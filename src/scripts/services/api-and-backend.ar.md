كل تطبيق وموقع ونظام أعمال يعتمد على نظام خلفي (Backend): كود الخادم وقاعدة البيانات وعمليات الربط التي تخزن البيانات وتطبق القواعد وتتواصل مع الأنظمة الأخرى. وعندما يكون الباك إند ضعيفًا، يصبح كل ما بُني فوقه بطيئًا أو هشًا أو غير آمن.

نحن نصمم ونبني أنظمة خلفية آمنة وسريعة وسهلة التطوير.

## ماذا نبني

- **واجهات REST API** لتطبيقات الويب والجوال، موثقة لفريقك أو لشركائك.
- **ربط الأنظمة** مع بوابات الدفع وشركات الشحن والرسائل النصية وواتساب وبرامج الحسابات والمنصات الحكومية، مثل [منظومة الإيصال الإلكتروني لمصلحة الضرائب المصرية](/projects/egypt-eta).
- **قواعد بيانات** مصممة لبياناتك، مع نسخ احتياطي وترحيل منظم للبيانات.
- **المصادقة والصلاحيات**: الحسابات، والأدوار، ودخول المسؤولين، وسجلات التدقيق.
- **مزايا لحظية**: تحديثات مباشرة، ومحادثات، وإشعارات.
- **مهام في الخلفية**: مهام مجدولة، واستيراد وتصدير البيانات، وعمليات مؤتمتة.

## مبني ليدوم

- **الأمان أولًا**: اتصالات مشفرة، وتعامل آمن مع كلمات المرور، وحدود لعدد الطلبات، وصلاحيات بأقل قدر لازم.
- **الأداء**: تخزين مؤقت، واستعلامات فعالة، وقابلية للتوسع مع زيادة الزيارات.
- **المراقبة**: تتبع الأخطاء، وفحص توفر الخدمة، والسجلات، لاكتشاف المشكلات قبل أن يبلغ عنها المستخدمون.
- **التوثيق والاختبارات**، ليستطيع أي مبرمج آخر استكمال العمل.
- **الاستضافة** على بنية سحابية موثوقة، في حسابات تملكها أنت.

## للمنشآت في السعودية والإمارات

تتصل المشاريع في السعودية والإمارات عادةً بخدمات محلية: بوابة دفع مرخّصة، أو منصة (فاتورة) لدى هيئة الزكاة والضريبة والجمارك، أو خدمة الهوية الرقمية الوطنية لتسجيل الدخول. نبني هذه الروابط وفق الوثائق المنشورة لكل مزوّد، ونستضيف النظام الخلفي لدى المزوّد وفي المنطقة التي تختارها. ابدأ بدليل [بوابات الدفع في السعودية](/blog/payment-gateways-saudi-arabia) و[قائمة المطوّرين لربط واجهة زاتكا البرمجية](/blog/zatca-api-integration-developer-checklist)، واطّلع أيضًا على صفحتَي [السعودية](/saudi-arabia) و[الإمارات](/uae).

## أسئلة شائعة

### هل يمكنكم ربط نظامنا بواجهة API لشركة أخرى؟

نعم. ربط الأنظمة جزء كبير من عملنا، سواء مع بوابات الدفع أو شركات الشحن أو برامج الحسابات أو المنصات الحكومية أو أنظمة الشركاء.

### هل يمكنكم استلام باك إند قائم بالفعل؟

نعم. نبدأ بمراجعة الكود والأمان والاستضافة، ثم نصلح المشكلات العاجلة، وبعدها نستكمل التطوير.

### أين ستتم استضافة الباك إند؟

لدى مزودي خدمات سحابية معروفين، يتم اختيارهم حسب ميزانيتك وحجم الزيارات، مع تسجيل الحسابات باسم شركتك.
