Sie haben einen Beitrag beworben oder eine Google-Kampagne gestartet. Das Dashboard
zeigt Hunderte von Klicks zu einem vernünftigen Preis. Dann vergeht eine Woche, und
das Telefon klingelt kaum. Die übliche Schlussfolgerung lautet, dass Anzeigen "für
unser Geschäft nicht funktionieren". Häufiger haben die Anzeigen gut funktioniert.
Die Klicks sind nur an einem Ort gelandet, der den Menschen keinen Grund zum Bleiben
gab.

## Warum die Startseite Anzeigen-Traffic verliert

Ihre Startseite ist für alle gebaut. Wer auf eine Anzeige geklickt hat, ist anders.
Diese Person hat ein ganz bestimmtes Versprechen gesehen, etwa einen Rabatt auf
Zahnaufhellung oder einen kostenlosen Vor-Ort-Termin für eine Küche, und getippt, um
mehr darüber zu erfahren. Auf einer allgemeinen Seite muss sie danach suchen. Auf dem
Handy, mit langsamer Verbindung und dem Daumen schon auf dem Zurück-Button, tun das
die meisten nicht. Sie gehen, und Sie zahlen trotzdem für den Klick.

## Was eine Landingpage eigentlich ist

Eine Landingpage ist eine einzelne Seite, die für eine Kampagne gebaut wird. Sie hat
kein vollständiges Menü und keine Ablenkungen. Sie wiederholt das Versprechen aus der
Anzeige, erklärt es gerade so weit wie nötig und bittet den Besucher, eine einzige
Sache zu tun.

Sie kann auf Ihrer eigenen Domain liegen, zum Beispiel `ihrefirma.com/angebot`,
sodass Tracking und Daten unter Ihrer Kontrolle bleiben.

## Was eine Landingpage konvertieren lässt

### Ein Angebot

Die Überschrift sollte zu der Anzeige passen, die die Person gerade angeklickt hat,
möglichst mit denselben Worten. Wenn in der Anzeige "Kostenlose Beratung diese Woche"
steht, sollte genau das oben auf der Seite stehen, nicht "Willkommen bei unserem
Unternehmen".

### Eine Handlung

Legen Sie fest, was ein gutes Ergebnis ist, bevor irgendetwas gestaltet wird: eine
WhatsApp-Nachricht, ein Anruf, eine Buchung. Machen Sie das zum offensichtlichen
nächsten Schritt, wiederholen Sie ihn nach jedem Abschnitt und entfernen Sie alles,
was damit konkurriert.

### Ein WhatsApp-Button und ein kurzes Formular

In Ägypten schicken viele Menschen lieber eine WhatsApp-Nachricht, als ein Formular
auszufüllen. Andere hinterlassen lieber eine Nummer und werden zurückgerufen. Bieten
Sie beides an:

- **Einen WhatsApp-Button**, der einen Chat mit einer vorausgefüllten Nachricht
  öffnet, sodass Sie wissen, aus welcher Kampagne er stammt
- **Ein kurzes Formular**: Name, Telefonnummer und höchstens eine Frage, die Ihnen
  hilft, den Lead einzuschätzen

Jedes zusätzliche Formularfeld kostet Sie Leads.

### Schnell auf dem Handy

Die meisten Anzeigenklicks kommen von Handys, oft über mobile Daten. Eine langsame
Seite verliert Menschen, bevor sie die Überschrift gelesen haben. Komprimieren Sie
Bilder, verzichten Sie auf schwere Slider und automatisch startende Videos, und
testen Sie auf einem Android-Handy der Mittelklasse, nicht nur im Büro-WLAN.

### Belege

Menschen sind vorsichtig bei einem Unternehmen, das sie über eine Anzeige gefunden
haben. Zeigen Sie ihnen:

- Echte Fotos Ihrer Arbeit, Ihres Ladens oder Ihres Teams
- Kurze Bewertungen echter Kunden, mit deren Erlaubnis, ihre Namen zu nennen
- Preise oder eine Preisspanne, wenn Sie sie nennen können
- Ihre Adresse, Ihre Öffnungszeiten und wie schnell Sie antworten

Erfinden Sie keine Bewertungen oder Zahlen. Besucher merken das.

### Tracking

Installieren Sie das **Meta Pixel** für Facebook- und Instagram-Anzeigen und das
**Google-Ads-Conversion-Tag** (oder den Google Tag Manager mit GA4) für
Google-Kampagnen. Legen Sie dann fest, was als Conversion zählt: ein abgeschicktes
Formular, ein Tipp auf den WhatsApp- oder Anruf-Button. Ohne das können Sie eine gute
Kampagne nicht von einer schlechten unterscheiden.

## So messen Sie den Erfolg

Klicks sind keine Ergebnisse. Messen Sie stattdessen:

1. **Conversion-Rate**: Leads geteilt durch die Besucher der Seite.
2. **Kosten pro Lead**: gesamte Werbeausgaben geteilt durch die Zahl der Leads.
3. **Lead-Qualität**: wie viele Leads zu echten Gesprächen wurden und wie viele zu
   Kunden. Eine einfache Tabelle genügt.
4. **Quelle**: Ergänzen Sie jeden Anzeigenlink um UTM-Parameter, damit Sie wissen,
   welche Kampagne welchen Lead gebracht hat.

Ändern Sie dann immer nur eine Sache auf einmal, sonst wissen Sie nicht, was gewirkt
hat.

## Was eine Landingpage in Ägypten kostet

Das sind typische Marktspannen, kein Angebot, und sie schwanken stark.

- **Eine einzelne Seite auf Basis einer Vorlage oder eines Page Builders**: oft
  irgendwo zwischen 5.000 und 20.000 EGP, je nach Design, Texten und Einrichtung.
- **Eine individuell gestaltete Seite** mit vollständigem Tracking, angebunden an ein
  CRM oder eine Tabelle, in der die Leads eingehen: mehr, denn jede Anbindung ist
  echte Arbeit.
- **Mehrere Seiten für verschiedene Kampagnen**: Der Preis richtet sich danach, wie
  viele es sind und wie unterschiedlich sie ausfallen.

Fragen Sie, ob der Preis Texte, Pixel und Conversion-Tags, Tests und Hosting
einschließt. Wenn Sie zusätzlich eine vollständige Unternehmenswebsite brauchen,
erklärt
[was eine Unternehmenswebsite in Ägypten kostet](/blog/company-website-cost-egypt),
wie sich dieses Projekt unterscheidet.

## Häufige Fehler

- **Jede Anzeige auf die Startseite schicken**
- **Eine Überschrift, die nicht zur Anzeige passt**, sodass Besucher glauben, sie
  hätten den falschen Link angeklickt
- **Lange Formulare**, die alles abfragen, bevor überhaupt Kontakt entsteht
- **Kein Tracking**, oder ein installiertes Pixel ohne definierte Conversion-Events
- **Leads, auf die niemand antwortet**: Eine WhatsApp-Nachricht, die einen Tag liegen
  bleibt, ist meist ein verlorener Kunde, egal wie gut die Seite ist
- **Zu frühes Urteilen**, auf Grundlage von wenigen Tagen an Daten

> Eine Landingpage macht aus einem schwachen Angebot kein starkes. Sie macht es
> leicht, ein gutes Angebot anzunehmen.

## Häufige Fragen

### Kann ich statt einer Landingpage meine Facebook-Seite nutzen?

Das können Sie, und Click-to-WhatsApp-Anzeigen umgehen die Website ganz. Der Preis
dafür ist weniger Kontrolle über das Design und weniger Tracking-Daten. Eine
Landingpage auf Ihrer eigenen Domain gibt Ihnen beides.

### Wie lange dauert es, eine Landingpage zu erstellen?

Wenn Angebot, Texte und Fotos bereitstehen, lässt sich eine einzelne Seite meist
innerhalb von ein bis zwei Wochen erstellen und testen. Das Warten auf Inhalte ist die
übliche Verzögerung.

### Brauche ich für jede Anzeige eine eigene Seite?

Nicht für jede Anzeige, aber meist für jedes Angebot oder jede Zielgruppe. Fünf
Anzeigen für denselben Rabatt können sich eine Seite teilen. Geschäftskunden und
Privatkunden brauchen getrennte Seiten, weil sich die Worte und die Belege
unterscheiden.

### Woran erkenne ich, ob das Problem bei der Anzeige oder bei der Seite liegt?

Bekommt die Anzeige wenige Klicks, liegt das Problem bei der Anzeige: beim Bild, beim
Text oder bei der Zielgruppe. Bekommt sie Klicks, die Seite aber kaum Leads, liegt das
Problem meist bei der Seite oder beim Angebot. Erst das Tracking erlaubt es Ihnen,
beides auseinanderzuhalten.
